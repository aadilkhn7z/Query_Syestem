Built a responsive query submission system using HTML, CSS, JavaScript, PHP, and
Apache/XAMPP to collect and manage user queries efficiently. Developed an interactive formbased interface with a modern and responsive UI, allowing users to submit queries seamlessly.
Implemented AJAX using the Fetch API to send data asynchronously without page reloads,
improving user experience and application performance. Integrated real-time browser
notifications for instant query alerts and used PHP to dynamically process and store submitted
data on the server side.
